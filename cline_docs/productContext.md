# Contexto del Producto (Product Context)

## Propósito del Proyecto
Tangara 2026 es una plataforma web de Inteligencia Ambiental Urbana diseñada específicamente para la ciudad de Cali, Colombia, como parte de una Hackathon. El objetivo principal es ofrecer a la ciudadanía y entidades de control una herramienta profesional, atractiva y fácil de entender para monitorear la calidad del aire.

## Problema que Resuelve
La calidad del aire suele presentarse en tablas de datos complejas que el ciudadano común no entiende ni sabe cómo interpretar para su día a día. Tangara 2026 democratiza esta información cruzándola con el contexto local y cultural.

## Solución Propuesta (El MVP)
1. **Visualización Clara**: Un dashboard que presenta el Índice de Calidad del Aire (ICA) de manera prominente, junto con un mapa dividido por comunas para identificar zonas críticas.
2. **Histórico y Tendencias**: Gráficas que permiten ver cómo se ha comportado el aire en la última semana o meses, dando perspectiva.
3. **Desglose de Contaminantes**: Explicación educativa de qué se está midiendo (PM2.5, Ozono, etc.) y de dónde proviene.
4. **Tangara Chat (Asistente IA)**: El diferenciador clave. Un chatbot que no solo da datos, sino que sugiere "borondos" (actividades) adaptados a la calidad del aire actual, hablando en la jerga local caleña para mayor cercanía y engagement.
